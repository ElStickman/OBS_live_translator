# Security policy

## Supported versions

Security fixes are provided for the latest released version and the current
default branch when practical.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature under the repository's **Security** tab. If it
is not enabled, contact the repository owner privately through their GitHub
profile and ask for a secure reporting channel without including exploit details.

Include the affected version, operating system, reproduction steps, impact, and
any proposed mitigation. Please allow reasonable time for acknowledgement and a
fix before public disclosure.

Never include recorded audio, access tokens, personal names, or full diagnostic
logs unless explicitly requested through a private channel.
