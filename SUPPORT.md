# Support

This project is maintained on a best-effort basis and is provided without a
warranty under the MIT license.

- Use GitHub Issues for reproducible bugs and feature requests.
- Use GitHub Discussions for setup questions and general help when enabled.
- Use the private process in `SECURITY.md` for vulnerabilities.

Before requesting help, read `README.md`, search existing issues, run the latest
release, and include the application version, Windows version, GPU, audio source,
and relevant error text. Remove personal or sensitive information from logs.

Sponsorship supports maintenance but does not purchase a service-level agreement,
guaranteed response time, or control over the roadmap.
